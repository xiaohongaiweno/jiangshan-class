# 「江山课堂」K12 产品规划

> 版本：1.0（2026-11-10）
> 依据：统编版初中历史教科书（2024/2025/2026 滚动新教材）逐册逐课调研
> 产品形态：基于「江山时序」历史地图引擎的课堂教学课件播放器 + 学生复习工具

---

## 1. 产品定位

**「江山课堂」= 面向初中历史教学的交互式地图课件系统。**

- 教师端：网页版课件播放器，上课投屏按幕推进，每一幕 = 地图定格画面 + 旁白 + 板书要点。
- 学生端：课后复习链接、舆图寻址课本题池、中考专题串讲。
- 底座：完全复用「江山时序」既有引擎（2440 年疆域政区、496 条编年大事、694 处城池、125+ 人物行迹、深链协议、embed 模式），新增「课件剧本层」。

**差异化切口**：2024 新课标将「读历史地图」列为明确教学要求（新增「读地图」栏目与《如何阅读历史地图》学史方法课），但市面教辅均为静态纸质图。交互式读地图工具目前是空白市场。

## 2. 教材调研结论

### 2.1 教材全景（统编版滚动新教材）

| 册 | 版本 | 内容范围 | 课数 | 地图适配度 |
|---|---|---|---|---|
| 七上 | 统编 2024 | 史前 → 三国两晋南北朝 | 21 课 + 3 学史方法 | 高（除第 1–5 课） |
| 七下 | 统编 2024 | 隋唐 → 明清（至鸦片战争前） | 22 课 + 1 活动课 | 最高 |
| 八上 | 统编 2025 | 鸦片战争 → 人民解放战争 | 21 课 + 1 活动课 | 中（需补近代事件图层） |
| 八下 | 统编 2025 | 新中国成立 → 新时代 | 约 20 课 | 低（靠古今对照讲） |
| 九上 | 统编 2026 | 世界古代史 → 一战前 | 22 课 | 无（范围外） |
| 九下 | 统编 2026 | 一战后 → 当代世界 | 20 课 | 无（范围外） |

### 2.2 新教材关键机会

1. **「读地图」栏目 + 学史方法《如何阅读历史地图》**：全国统一必讲、不随进度波动，做成通用交互课作为拉新钩子。
2. **「学史崇德」栏目**：张骞持汉节、诸葛亮鞠躬尽瘁等人物叙事，对应引擎 125+ 人物行迹数据。
3. **活动课 + 跨学科主题学习**：舆图寻址游戏可包装为活动课实施方案。

### 2.3 产品范围决策

- **核心盘 = 七年级两册**（中国古代史）：逐课 100% 覆盖，产品主体。
- **扩展盘 = 八年级两册**（中国近现代史）：需补「事件类图层」（战争、条约、割让/租借地、长征路线、抗战态势），数据扩建约占内容工程量 40%。
- **九年级世界史**：不做疆域课件，仅提供「中西对照时间轴」轻模块（同一时间轴左右分栏）。

## 3. 逐课覆盖分层

### A 类 · 地图原生强相关（现成资产，约 40%）

- 七上：第 6 战国变革、第 9 秦统一、第 10 秦末起义、第 12 大一统巩固、第 14 丝绸之路、第 16 三国鼎立、第 17 西晋与内迁、第 19 北朝民族交融
- 七下：第 1 隋朝兴亡（大运河图层）、第 2 贞观之治、第 3 开元盛世、第 4 安史之乱、第 5 民族交往、第 6 中外交流（玄奘行迹）、第 8 北宋政治、第 9 辽夏宋并立、第 10 金宋对峙、第 11 元朝统一、第 15 明朝统治、第 16 明朝对外关系（郑和航线）、第 17 明亡清建、第 18 清朝边疆治理

### B 类 · 需补轻量数据（政区沿革卡片 + 人物地点，约 30%）

七上：第 7 百家争鸣、第 11 文景之治、第 13 东汉兴衰、第 18 江南开发、第 20 魏晋科技文化
七下：第 12–14 经济/对外/科技（市舶司、泉州、活字印刷地）

### C 类 · 需补中等数据（约 20%）

- 七上第 1–5 课（史前/夏商西周/春秋）：新建「考古与文明起源图层」——周口店、河姆渡、半坡、良渚、陶寺、二里头、殷墟等遗址点 + 文化圈示意，同时服务第 21 活动课。
- 七上第 8、15 课：以人物地图为主（司马迁壮游等）。
- 八上：近代战争与条约图层、长征路线（行迹协议现成，缺路线点）、抗战态势。
- 八下：一五计划工业布局、经济特区、港澳回归——多用事件落点 + 古今透视镜。

### D 类 · 不依赖地图（约 10%）

- 学史方法工具页：年号纪年换算器、交互读地图练习器、出土文物解读卡、历史人物评价卡。
- 活动课：七上《从考古发现看中华文明起源》配考古点图层；七下《传统节日的起源与传承》配节令民俗地图。

## 4. 功能架构

### 4.1 课件播放器（教师课堂用）— `classroom/`

- 教材树导航：学段 → 册 → 单元 → 课，与统编目录一一对应，标注教材版本。
- 每课标准结构：导入 → 新授分幕 → 课堂活动 → 小结 → 课后探索二维码/链接。
- 幕类型：`map`（地图定格）、`journey`（人物行迹自动巡礼）、`timeline`（时间轴区间播放）、`quiz`（课堂快测）、`activity`（活动课任务）。
- 投屏模式：全屏 + 大字号，翻页笔（PageUp/PageDown）与键盘支持，每幕一键回放。
- 教师自定义：场景开关、旁白编辑，localStorage 保存，可导出 JSON。

### 4.2 学史方法工具箱（新课标对标）

- 《如何阅读历史地图》交互课（旗舰模块）、年号纪年换算、读图实战（舆图寻址）。

### 4.3 学生端

- 课后复习：按课访问精简场景（纯链接，无注册）。
- 舆图寻址·课本模式：题目池从当课考点生成。
- 中考复习专题：中国古代史疆域演变跨册串讲。

### 4.4 内容生产流水线

- 剧本 JSON Schema + 校验 CLI（`classroom/validate_lessons.cjs`）。
- MCP 批量初稿 + 史学人工校对双签制度。
- CLI 截图管线自动产出导学案插图/试卷配图。

### 4.5 管理与分发（后续阶段）

- 无账号个人版永久免费 → 学校版按年授权（教师账号、班级、任务布置、进度报告）。

## 5. 剧本 Schema（课件 = JSON）

```json
{
  "id": "q7x-u1-l01",
  "textbook": "统编版(2024)",
  "grade": "七年级下册",
  "unit": "第一单元 隋唐时期：繁荣与开放的时代",
  "lesson": 1,
  "title": "隋朝统一与灭亡",
  "duration": 40,
  "scenes": [
    {
      "type": "map",
      "title": "导入：杨坚代周建隋",
      "narration": "……",
      "board": ["板书要点"],
      "link": { "year": 581, "place": "长安" }
    },
    { "type": "timeline", "title": "……", "narration": "……", "link": { "from": 581, "to": 589 } },
    { "type": "journey", "title": "……", "narration": "……", "link": { "person": "xuanzang", "autoplay": 1 } },
    {
      "type": "quiz",
      "title": "课堂快测",
      "items": [
        { "q": "……", "options": ["A", "B", "C", "D"], "answer": 1, "explain": "……", "link": { "year": 611, "place": "洛阳" } }
      ]
    },
    { "type": "activity", "title": "……", "narration": "……", "link": { "year": -121, "quiz": 1 } }
  ],
  "explore": [{ "title": "课后探索", "url": "https://…/?year=611&place=洛阳" }]
}
```

驱动方式（技术结论，已核实源码）：

- 主地图为本页 SVG 渲染（无 iframe），`embed=1` 隐藏站点 chrome 保留紧凑时间轴；URL 参数在 boot 期一次性解析（`js/app.js` `_restoreFromQuery`）。
- 项目无 postMessage 通道 → 播放器通过**修改同源 iframe 的 src** 驱动地图（`embed=1` + `year/place/person/hover/zoom/polity/from/to/lock/autoplay/quiz` 参数）；`quiz` 取值被忽略，传 `quiz=1` 即可。
- embed 模式有防滚动遮罩，地图首次交互需点击一次（播放器旁白中提示）。

合计 **86 课可播放**，manifest 登记全六册真实目录，未完成课标记 `pending`。全部课件的深链地名经 MCP `inspect_place` 校验可解析，剧本经 `classroom/validate_lessons.cjs` 校验。

已实现的播放器功能：教材树导航、五类场景（地图/人物行迹/时间轴/快测/活动）、投屏模式（全屏 + 字号联动）、翻页笔与键盘、教师自定义（场景开关 + 旁白编辑 + localStorage + 导出 JSON）、学史方法工具箱（纪年换算）、学生复习模式（`?mode=student`）、课后探索深链、进度记忆。

已实现的题池功能（`classroom/bank.html`）：从全部 ready 课件自动汇总 **175 题 / 86 课**，支持按册/单元/课/关键词筛选与「只要可定位地名」过滤；顺序练习、随机 10/20 题、限时挑战（每题 30 秒）、错题重做；每题带地名锚点（题目自带 `link` 优先，缺失时回落本课主地图画面），答后一键回看地图；本机错题本、正确率统计、错题导出 JSON。

已实现的中西对照时间轴（`classroom/compare.html`）：九年级世界史复习用——**前 8 世纪—21 世纪逐世纪分栏**，上栏中国朝代（跨世纪延续标注），下栏世界史节点（**60 项**，按政治/军事/经济/文化/科技/交流/社会分类着色）；点击世纪查看双方详情，任一时期可「在舆图中查看此时期疆域」（早于前 403 年自动钳制到数据起点）；支持年份跳转（`-221`/`前221`）、关键词检索、分类筛选、键盘左右翻世纪、`?c=前3` 深链与打印复习单（含打印专用排版）。

已实现的班级任务（学校版离线包，`classroom/teacher.html` + `classroom/task.html`）：教师工作台管理班级与任务——按册/单元/课选范围、设题量与限时、可设截止日；任务编码为 UTF-8 base64url **学生链接**（同一任务同一 seed 出同一套题，可复现）；学生打开链接作答、交卷后**下载结果 JSON**；教师批量导入结果自动汇总（人数/平均分/及格率/逾期，按成绩排序表格，CSV 导出）。全部数据存本机 localStorage，**无需服务器**；后续接服务端时任务/结果 Schema 可直接复用。

已实现的服务端账号体系（`server/index.js`，零依赖 Node + 内置 `node:sqlite`，同时托管静态站点）：教师用户名/密码注册登录（scrypt 加盐、HttpOnly 会话 Cookie 7 天）；班级含 6 位加入码；学生凭「班级码 + 学号/姓名 + 密码」加入并登录；任务与提交入库，**服务端重算得分与逾期**、一人一任务仅可提交一次；教师端实时成绩与统计、CSV 导出；支持导入旧版离线结果 JSON。前端同一套页面双模式：检测到 `/api/health` 即走账号版，否则自动回落 localStorage 离线版。

尚未实现（后续阶段）：服务端增强项（邮箱验证、教师批量导入学生名单、家长端与学期报告导出）、考古文明起源图层（需在主引擎新增遗址点位渲染与图例开关，非数据可完成项）、抗战态势图层（多线交战态势图，需专项设计）。已补齐：教师改密接口 + 管理员 CLI 找回密码（`scripts/reset_teacher_password.js`）、全站 Service Worker 离线缓存（`sw.js`）、八年级近现代专题走廊图层——红军长征路线、滇缅公路、中印公路（史迪威公路）、驼峰航线（`js/map_data.js`，1934—1945 年随版图显示，1942/1944/1945 年份过滤已实测）。八下第六、七单元 6 课与九年级仍按审校流程保留 pending（九年级世界史由 `compare.html` 中西对照时间轴替代）。

## 7. 商业模式

- 个人教师/学生免费无注册 → 口碑获客；学校/区域教育局授权 = 全册课件 + 自定义工具 + 班级功能 + 培训。
- 教辅衍生：导学案、试卷配图授权。
- 合规：近现代史课件严格对齐教材表述，建立审校流程；CHGIS 郡级数据仅限教学展示，商业合同明确教学用途；课件保留「示意性近似边界」声明。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 内容校对量大 | 只做教材明确提到的知识点，宁少勿错；双签校对 |
| 教材滚动改版 | 剧本按「教材版本 + 课次」结构化，改版时逐课替换 |
| 示意边界争议 | 保留免责声明，转化为「重趋势轻测绘」教学话术 |
| 数据许可 | 商业路径优先 polity 疆域层，郡府级依赖最小化 |
